# KcalScore – User Stories

| # | User story | Priority |
|---|---|---|
| 1 | As a user, I want to enter a barcode so that I can look up a food quickly. | Must |
| 2 | As a user, I want to see a food's calories so that I can track my intake. | Must |
| 3 | As a user, I want one simple score out of 100 so that I know how healthy a food is without reading labels. | Must |
| 4 | As a user, I want to add a food with a portion size to today's log so that my calories are accurate. | Must |
| 5 | As a user, I want to see my daily calorie total so that I know how much I've eaten. | Must |
| 6 | As a user, I want to search for a food by name so that I can find foods without a barcode. | Should |
| 7 | As a user, I want an average Food Score for my day so that I can see how healthy my day was overall. | Should |
| 8 | As a user, I want a clear message when a food isn't found so that I'm not confused. | Should |
| 9 | As a user, I want to scan a barcode with my camera so that I don't have to type it. | Could |

## Acceptance criteria (examples)
- **Story 3:** Done when every food shows a score from 0 to 100, and foods with missing data show "Score unavailable".
- **Story 5:** Done when the total updates straight away each time a food is added or removed.
